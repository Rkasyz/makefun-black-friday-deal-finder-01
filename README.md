[make.fun bounty: Build the best real Black Friday deal finder](https://make.fun/bounty/black-friday-deal-finder-01)

FridayFinds is a static Black Friday deal finder with 24 real deals, each
checked on 27 November 2026 at Amazon, Best Buy, Dell and Walmart. Total
savings $5,658.09, including 10 new lows.

- Search, category chips, store and discount filters, four sort orders.
- Each deal has a detail page with the verdict reason, evidence and source.
- No external loads: system fonts and inline SVG only; only the store links
  leave the page.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Generates the site into the output directory.
